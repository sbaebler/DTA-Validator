# Glossar

| Begriff | Erläuterung |
|---|---|
| **AAG** | Aufwendungsausgleichsgesetz — Erstattungsverfahren U1/U2 im Arbeitgeberdatenaustausch |
| **Abrechnungszentrum** | Dienstleister, der im Auftrag von Leistungserbringern abrechnet |
| **AMBO** | § 301-Nachrichtentyp: Rechnungssatz ambulantes Operieren |
| **ANFM** | § 301-Nachrichtentyp: Anforderung medizinische Begründung |
| **Anlage 16 / SECON** | Security-Schnittstelle der Gemeinsamen Grundsätze Technik (Signatur/Verschlüsselung) |
| **ARGE·IK** | Arbeitsgemeinschaft Institutionskennzeichen, angesiedelt bei der DGUV; vergibt IK |
| **AUFN** | § 301-Nachrichtentyp: Aufnahmeanzeige stationäre Behandlung |
| **Auftragsdatei / Auftragssatz** | Unverschlüsselte Begleitdatei mit Transport-Metadaten (Endung `.AUF`), Festsatzformat von **348 Byte** nach Anlage 2 GGT; entfällt bei Übermittlung über KIM |
| **Belegannahmestelle** | Stelle, die Urbelege (Verordnungen, Leistungsnachweise) entgegennimmt |
| **CMS** | Cryptographic Message Syntax (RFC 5652), Nachfolger von PKCS#7 |
| **DAV / Datenannahmestelle** | Entschlüsselungsbefugte Stelle, die Nutzdaten annimmt und weiterleitet |
| **DEÜV** | Datenerfassungs- und -übermittlungsverordnung (Arbeitgeber-Meldeverfahren) |
| **DiGA** | Digitale Gesundheitsanwendung; Abrechnung fällt unter § 302 SGB V |
| **DKG** | Deutsche Krankenhausgesellschaft — Vertragspartner der § 301-Vereinbarung |
| **DTA** | Datenträgeraustausch; heute Sammelbegriff für den elektronischen Abrechnungsdatenaustausch |
| **EBZ** | Elektronisches Beantragungs- und Genehmigungsverfahren (Zahnärzte) |
| **EDIFACT** | UN/EDIFACT — Syntaxstandard, auf dem die GKV-Nachrichtenformate aufsetzen |
| **eGK** | Elektronische Gesundheitskarte |
| **ENTL** | § 301-Nachrichtentyp: Entlassungsanzeige |
| **eXTra** | XML-Transportstandard für das Arbeitgeber-Meldeverfahren |
| **FEHL** | § 301-Nachrichtentyp: Fehlernachricht |
| **FKT** | Segment "Funktion" — enthält u. a. Absender/Empfänger-IK; verfahrensübergreifend genutzt |
| **GGT** | Gemeinsame Grundsätze Technik nach § 95 SGB IV |
| **GKV-KS** | GKV-Kommunikationsserver (Anlage 13 GGT) |
| **IK** | Institutionskennzeichen — 9-stellige Kennung von Leistungserbringern und Kostenträgern |
| **INV** | Segment "Information des Versicherten" |
| **ITSG** | Informationstechnische Servicestelle der GKV GmbH — Trust Center, Systemuntersuchung |
| **KIM** | Kommunikation im Medizinwesen (vormals KOM-LE) — sicherer E-Mail-Dienst der TI |
| **KKS** | Krankenkassenkommunikationssystem — Standardverfahren für Auftrags-/Nutzdatenaustausch |
| **KOUB** | § 301-Nachrichtentyp: Kostenübernahme |
| **KTR-Datei / Kostenträgerdatei** | Amtliches Verzeichnis der Daten- und Belegannahmestellen |
| **KVNR** | Krankenversichertennummer |
| **LE** | Leistungserbringer |
| **MBEG** | § 301-Nachrichtentyp: Medizinische Begründung Verlängerung |
| **MD / MDK** | Medizinischer Dienst |
| **NAD** | Segment "Name und Adresse" |
| **Nutzdatendatei** | Verschlüsselte Datei mit den fachlichen Abrechnungsdaten |
| **PKCS#7** | Cryptographic Message Syntax Standard; Basis der SECON-Verarbeitung |
| **PLAA** | § 105 SGB XI-Nachrichtentyp: Abrechnungsdaten Pflege |
| **PLGA** | § 105 SGB XI-Nachrichtentyp: Gesamtaufstellung der Abrechnung Pflege |
| **Positionsnummer** | Abrechnungsschlüssel für Heil- und Hilfsmittel (Hilfsmittel: 10-stellig) |
| **PZN** | Pharmazentralnummer |
| **RECH** | § 301-Nachrichtentyp: Rechnungssatz stationär/teilstationär |
| **SAMU** | § 301-Nachrichtentyp: Sammelrechnung/Sammelüberweisung (Rückmeldung der Kasse) |
| **SLGA** | § 302-Nachrichtentyp: Gesamtaufstellung der Abrechnung ("Sammelrechnung … Gesamtaufstellung") |
| **SLLA** | § 302-Nachrichtentyp: Abrechnungsdaten / Leistungsabrechnung |
| **Sonstige Leistungserbringer** | Sammelbegriff § 302 SGB V: Heilmittel, Hilfsmittel, häusliche Krankenpflege, Haushaltshilfe, Krankentransport, DiGA u. a. |
| **TA** | Technische Anlage |
| **TI** | Telematikinfrastruktur |
| **Trennungsgebot** | Datenschutzrechtliche Trennung von Auftrags- (Klartext) und Nutzdaten (verschlüsselt) |
| **UNA/UNB/UNZ** | EDIFACT-Servicesegmente: Trennzeichenvorgabe / Dateikopf / Dateiende |
| **Urbeleg** | Papier-/Original-Nachweis zur Abrechnung (Verordnung, Leistungsnachweis) |
| **Verarbeitungskennzeichen (VKZ)** | Steuert Erstabrechnung / Nachforderung / Wiedereinreichung im Korrekturverfahren |
| **Verfahrenskennung** | Schlüssel für das Fachverfahren im Auftragssatz (Stellen 20–24) und im Transferdateinamen; im LE-Datenaustausch 5-stellig (`E`/`T` + 3 Stellen Verfahren + Versionsziffer), im Verkehr mit der Rentenversicherung 2-stellig |
| **VERL** | § 301-Nachrichtentyp: Verlängerungsanzeige |
| **ZAAO** | § 301-Nachrichtentyp: Zahlungssatz zu AMBO |
| **ZAHL** | § 301-Nachrichtentyp: Zahlungssatz (Bestätigung/Ablehnung zu RECH) |
| **ZGUT** | § 301-Nachrichtentyp: Zuzahlungsgutschrift |
