# Ultra Big Bills

Sehr große bzw. umfangreiche synthetische Abrechnungen (Bills) als Last-, Volumen- und
Skalierungstests für den Validator. Alle Daten sind frei erfunden; die Belastbarkeit der
Fachsegmente steht in der jeweiligen README.
